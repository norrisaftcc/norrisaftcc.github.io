Lab PC safety

  • Use a private browser window. Sign out at the end.
  • Keep recovery codes on your phone or in a password manager, never on the lab PC.
  • Never commit a secret. A deleted file stays in History.

Make a public page: GitHub Pages, the short version

GitHub Pages turns files in a repo into a website. You write Markdown, a plain-text format. GitHub builds the page with a theme and publishes it. Two files are enough: _config.yml holds your name, one line about you, and the theme. index.md is the page.

  1. Create a public repo named your-username.github.io, with your GitHub username. On a free account, Pages works only with public repos.
  2. Add file, Create new file, _config.yml. Paste the first block below. Change the title and description. Commit.
  3. Add file, Create new file, index.md. Paste the second block. Change every line to your own. Commit.
  4. Open Settings, then Pages. Check that Source is Deploy from a branch, branch main, folder / (root).
  5. Wait a few minutes. The Actions tab shows a run named “pages build and deployment”. Then open https://your-username.github.io.

Everything here is public: the page, the repo, and every old version of every file. Put in only what you would print on a flyer. No phone number, no street address. Keep your full résumé in a private repo, and send it as a PDF.

_config.yml

title: Jordan Reyes
description: Network Technology student · Fayetteville, NC
remote_theme: pages-themes/hacker@v0.2.0
plugins:
  - jekyll-remote-theme
