# Jordan's public page

Jordan Reyes is a fictional student for the ITCC GitHub talk.

`index.html` in this folder is Jordan's public page. It is published at:

https://norrisaftcc.github.io/itcc26/jordan/

It ships with the ITCC talk page (`itcc26/` in `norrisaftcc.github.io`). Jordan's résumé is in a different repo, `norrisaftcc/jordan-resume`. That repo is private.

## Everything here is public

- Anyone can read every file in this folder.
- Anyone can read every old version of every file. Git keeps the history.
- Search engines can find the page.

So the page has only things that are OK for a stranger to read.

## What I left out on purpose

| Left out | Why |
|---|---|
| Phone number | Spam calls and scams. I give it to employers when I apply. |
| Street address | Not needed. City and state are enough. |
| Email address | Spam. The page says "Résumé available on request." |
| LinkedIn link | No real profile exists. The page says "LinkedIn: on request." |
| Full résumé PDF | It has my phone and email. It lives in the private repo `jordan-resume`. I send it on request. |
| Work-study supervisor names | Their information is not mine to publish. |
| Real IP addresses, passwords, keys | Never in any public repo. |

## How it is set up

- One file: `index.html`. The CSS is inside the file. No scripts. No outside files.
- The page works on a phone. It uses one column.
- GitHub Pages publishes it from the `norrisaftcc.github.io` repo, in the folder `itcc26/jordan/`.
